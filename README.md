# Thermally Induced Larval Mortality in Hybrid Clarias Catfish

Supplementary code and reproducible analyses associated with the manuscript:

**Thermally Induced Larval Mortality in Hybrid Clarias Catfish**

## Supplementary File S1

`Supplementary_Code_Parameters_S1.py`

This script reproduces:

1. Deterministic hatchery outputs reported in Table 2
2. Q10 multiplier calculations reported in the Results
3. The illustrative seasonal and multiyear climate scenario used for Figure 3

The long-term economic and genomic trajectories implemented in this script are scenario analyses and should not be interpreted as calibrated forecasts.
